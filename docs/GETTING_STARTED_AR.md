# دليل مشروع BikeStores — باللغة العربية

هذا المستودع يعرض مشروع **Data Engineering & Executive Analytics** باستخدام `SQL Server` و`Power BI`.

## أين أبدأ؟

1. افتح [README الرئيسي](../README.md) لعرض أهداف المشروع ونتائج مؤشرات الأداء.
2. اقرأ [معمارية البيانات](DATA_ARCHITECTURE.md) لفهم الجداول والعلاقات بين `Fact` و`Dimensions`.
3. اقرأ [سير عمل ETL](ETL_WORKFLOW.md)، ولاحظ الفرق بين مسار `etl` ومسار `dw`.
4. راجع [مقاييس الأداء](KPI_DICTIONARY.md) و[جودة البيانات](DATA_QUALITY.md).
5. نفّذ استعلامات الفحص الموجودة في `sql/read_only` **فقط على نسخة مصرح بها من قاعدة البيانات**؛ لا تشغل ملفات Schema أو الإجراءات تلقائيًا.
6. أضف صور صفحات Power BI بعد مراجعتها، ثم راجع [قائمة النشر](RELEASE_CHECKLIST_AR.md).

## حالة المشروع

- تم نشر تقرير Power BI وفتحه من المتصفح.
- تم استخراج وتوثيق جداول DW وETL وMonitoring وOrchestration من SQL Server.
- لم يتم إثبات إمكانية إعادة بناء قاعدة البيانات من الصفر من هذه الملفات وحدها.
- لم يتم إعداد `Scheduled Refresh` لأن الاتصال الحالي يعتمد على `SQL Server LocalDB`.

> ملفات SQL المرجعية ليست أمرًا بتنفيذ المشروع على قاعدة إنتاج. اقرأ التحذيرات الفنية أولًا.
